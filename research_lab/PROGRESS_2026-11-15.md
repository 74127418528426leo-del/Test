## Boundaries

128 queued tasks are **not** 128 GPUs or simultaneously alive 27B model
instances; the CPU test has a hard parallelism cap and runner timeout.
Neither 5-second Firefox VM target nor physical Acer i3-540 startup was
achieved by the model demo.

The actual CUDA-capable GPU server requires operator-provisioned
hardware and explicit spending authorization. The model API
credentials are not in this repository.
