PUPPY50 — MAINTAINED BROWSER EXPERIMENT

Modern web. A full network connection menu.

This experimental Debian Live edition is a second engineering track. It uses distribution-updated Firefox ESR and a Linux NetworkManager panel for choosing authorized wired and wireless connections.

Connect to Wi-Fi or Ethernet

Click the network icon in the bottom panel to see hardware-supported networks. Select only networks you are authorized to join. Passwords and captive portals must be completed normally; there is no bypass.

Use Ctrl+L to type any web address. No public website has yet been verified in this NEW Debian build until the independent QEMU tests pass.

Boot option toram requests a copy of the live filesystem into memory. It requires additional RAM and is not guaranteed on 2 GiB systems. This live pilot does not overwrite your existing OS.
