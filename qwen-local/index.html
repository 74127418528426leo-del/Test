Browser-storage fallback

If the browser reports a storage-space error, download the selected model file and load it directly. This avoids Wllama's persistent browser cache, but still needs enough RAM and may not work on iPhone Safari.

  1. Tap the download link and wait for Safari to finish the 696–731 MB download.
  2. Return here, tap Choose a downloaded GGUF file, then use Files to select the matching Q4 file from Downloads.
  3. Tap Load selected file from this device. The file is read locally and is not uploaded.
  4. If Safari closes this page, reopen it and select the downloaded file again.

Transparency

What this page does and does not do

Chat generation happens locally after the model loads. This page's code does not send your prompt to DeepSeek, ChatGPT, or an inference API, and it does not store chat history. Wllama runtime code is fetched from jsDelivr and runs in your browser; model weights come from LiquidAI's Hugging Face repository. Use prompts you are comfortable processing in this browser.

License and model sources

The GGUF model repository lists the LFM 1.0 license (not MIT). Read the terms before redistributing or adapting the weights. This site downloads the original public files and does not copy the 696–731 MB model into GitHub Pages.

Why can it still fail on iPhone?

The model file is only part of the memory requirement. Safari also needs working memory for WebAssembly, the context cache, and browser rendering. A 696 MB file does not mean the app needs only 696 MB of RAM. If Safari closes the tab or model loading fails, try again on a laptop; that does not mean the model is broken.
