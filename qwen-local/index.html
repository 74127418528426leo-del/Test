Why isn’t it running locally here?

GitHub Pages serves static files and does not provide model inference hardware. DeepSeek V4.1 Flash’s official model repository is roughly 510 GB, far beyond an iPhone 13’s storage and memory budget. A local build would need a very large multi-GPU server. This page links to DeepSeek’s hosted chat instead of pretending the model runs on your phone.

Can I connect this page to the API?

The API model name is deepseek-flash. API access is billed separately. A public page must not contain an API key; a secure API connection needs a private backend and server-side key storage. This launcher does not call the paid API.
